# 🐾 Pawsitive — Dog Training App

A React Native (Expo) app for iOS and Android that helps you train your dog with reward-based methods.

## Features

- **19 step-by-step training plans** across Foundations, Manners, Recall & Leash, Calm & Confidence and Tricks. Each one has a clear goal, numbered steps and trainer tips.
- **Training sessions**: a big clicker button that plays a click sound, vibrates and counts a success. A Miss button, undo, a live success rate over the last 10 reps, and a session timer. Your screen stays awake during a session.
- **Smart coaching**: tells you when you hit 80%+ over 10 reps (time for the next step), when your dog has missed 3 in a row (make it easier), and when you reach 5 minutes (end on a win).
- **Progress tracking**: skill status (Not started → Learning → Reliable → Mastered), current step, day streak, daily goal, a 7-day chart, progress by category and session history with notes.
- **A clicker you can use any time** to capture good behaviour, with switches for sound and vibration.
- **More than one dog**: each dog has its own progress and history.
- Light and dark mode. Everything is stored on the device, with no account needed.

## Run it on your phone

1. Install **Expo Go** from the App Store or Google Play.
2. On your computer (Node 20+):
   ```bash
   cd dog-trainer
   npm install
   npx expo start
   ```
3. Scan the QR code. On iPhone use the Camera app; on Android scan from inside Expo Go.
   Your phone and computer need to be on the same Wi-Fi. If they aren't, run `npx expo start --tunnel`.

## Install it as a standalone app

Build with [EAS](https://docs.expo.dev/build/introduction/). You don't need Xcode or Android Studio:

```bash
npx eas-cli@latest build --platform android --profile preview   # installable APK
npx eas-cli@latest build --platform ios                          # requires an Apple Developer account
```

src/lib/               State (AsyncStorage), stats, theme, clicker
